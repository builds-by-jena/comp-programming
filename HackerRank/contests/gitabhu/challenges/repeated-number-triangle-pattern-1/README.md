### 📝 Problem Statement
Problem Statement

Given an integer N, print a left-aligned number triangle where each row contains the same repeated number.

The triangle should contain N rows. In the ith row (1-indexed), print the number i exactly i times.

Each number should be separated by a single space.

Input Format

Constraints

Output Format

Sample Input 0

Sample Output 0

2 2
3 3 3
4 4 4 4
