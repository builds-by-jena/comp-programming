### 📝 Problem Statement
Problem Statement

Given an integer N, print a hollow left-aligned right triangle using the * (asterisk) character.

The triangle should contain N rows. The first and last rows are completely filled with *. For the remaining rows, only the first and last positions contain *, while all inner positions are represented by spaces.

Each star should be separated by a single space.

---

### 📥 Input / Output Specification
**Input:** * A single integer N.
**Output:** * Print a hollow left-aligned right triangle consisting of N rows using the * (asterisk) character.
