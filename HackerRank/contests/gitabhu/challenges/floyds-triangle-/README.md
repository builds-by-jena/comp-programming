### 📝 Problem Statement
Problem Statement

Given an integer N, print Floyd's Triangle containing N rows.

Floyd's Triangle is formed by printing consecutive natural numbers starting from 1. The first row contains 1 number, the second row contains 2 numbers, the third row contains 3 numbers, and so on until the Nth row.

Each number should be separated by a single space.

---

### 📥 Input / Output Specification
**Input:** * A single integer N.
**Output:** * Print Floyd's Triangle consisting of N rows.

* The numbers should appear in consecutive increasing order, starting from 1.

---

### 🧪 Sample Tests

#### Example 1
**Input:**
```
4
```
**Output:**

```
7 8 9 10
```
