### 📝 Problem Statement
Problem Statement

Given an integer N, print a left-aligned binary triangle consisting of 0s and 1s.

The triangle should contain N rows. The value printed at each position depends on the sum of its row and column indices (1-indexed):

Print 1 if (row + column) is even.
Print 0 if (row + column) is odd.

Each value should be separated by a single space.

Input Format

Constraints

Output Format

Sample Input 0

4

Sample Output 0

1
0 1
1 0 1
0 1 0 1
