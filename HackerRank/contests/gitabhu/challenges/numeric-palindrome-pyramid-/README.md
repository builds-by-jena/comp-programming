### 📝 Problem Statement
Problem Statement

Given an integer N, print a numeric palindrome pyramid.

The pyramid should contain N rows. In the ith row:

* Print numbers in increasing order from 1 to i.

* Then print numbers in decreasing order from i − 1 to 1.

* Appropriate leading spaces should be printed so that the pyramid is horizontally centered.

Each number should be separated by a single space.

---

### 📥 Input / Output Specification
**Input:** * A single integer N.
**Output:** * Print a numeric palindrome pyramid consisting of N rows

---

### 🧪 Sample Tests

#### Example 1
**Input:**
```
6
```
**Output:**
```
1
        1 2 1
      1 2 3 2 1
    1 2 3 4 3 2 1
  1 2 3 4 5 4 3 2 1
1 2 3 4 5 6 5 4 3 2 1
```
